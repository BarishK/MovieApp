# Movie App 🎬

**Vercel**
https://movie-app-swart-nine.vercel.app/

A modern and responsive movie browsing web application built with **Next.js (App Router)** and **Tailwind CSS**, powered by the **TMDB API**.

> ⚠️ **Note on Performance:** Since this project uses a free-tier public API service for movie data, initial requests or category switches might occasionally take a few seconds to load while the server wakes up.

## ✨ Features

- **Dynamic Categories:** Browse movies by genre with real-time category filtering.
- **Movie Details:** View comprehensive information including overview, release date, runtime, ratings, and genres.
- **Cast & Crew:** Explore main cast members for each movie.
- **Similar Movies:** Discover related films easily.
- **Persistent Favorites:** Save your favorite movies locally using `localStorage`.
- **Responsive Design:** Optimized for mobile, tablet, and desktop screens with smooth loading skeletons.

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Data Source:** TMDB (The Movie Database) API
- **Icons:** Tabler Icons
